# 📖 Alquranku — Al-Qur'an Website

**Alquranku** is a simple and user-friendly web application designed to make reading and exploring the Holy Qur'an more accessible. This project was created to provide a comfortable digital space for Muslims to read the Qur'an, understand its meanings, and listen to recitations anytime and anywhere.

## ✨ About The Project

Alquranku is an online Qur'an reading platform that provides all 114 surahs with Arabic text, Latin transliteration, Indonesian translations, and audio murottal. The website focuses on a clean, simple, and responsive interface to create a comfortable reading experience.

This project was built as a personal learning project to explore web development, API integration, and interactive website development while creating something useful and meaningful.

### 🚀 Features

- **114 Surahs:** Access the complete list of Qur'an surahs.
- **Arabic & Latin Text:** Read verses with Arabic script and Latin transliteration.
- **Indonesian Translation:** Understand the meaning of each verse.
- **Audio Murottal:** Listen to Qur'an recitations directly from the website.
- **Surah Search:** Quickly find surahs by name.
- **Bookmark:** Save your favorite surahs directly in your browser without creating an account.
- **Responsive Design:** Comfortable access across different screen sizes.
